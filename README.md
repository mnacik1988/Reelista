# Reelista

Монтаж рилсов «говорящая голова» прямо на телефоне: выбрал ролик → паузы вырезались сами → сохранил.

**Прототип v0.1** — один файл `index.html`, без сервера:
- звук ролика разбирается на устройстве (Web Audio), порог тишины подстраивается под каждый ролик;
- три уровня резки: «Мягко» / «Средне» / «Жёстко» (минимальная пауза 0.70 / 0.45 / 0.25 с, запас у слов 0.15 / 0.10 / 0.06 с);
- начало и конец ролика (тянулись к кнопке, молчали в конце) режутся всегда;
- просмотр с пропуском пауз, волна с подсвеченными вырезами, тап по волне — перемотка;
- сборка в реальном времени: canvas + MediaRecorder, между кусками запись на паузе;
- сохранение через «Поделиться» → «Сохранить видео» (на iPhone попадает в «Фото»).

Видео никуда не отправляется.

**v0.2 — титры** (два стиля: «Студия» — фраза целиком, звучащее слово красное; «Караоке» — 2–3 слова крупно, слово в плашке):
- телефон отправляет только звук: моно 16 кГц WAV (~2 МБ/мин), видео не уходит;
- сервер `worker/` (Cloudflare Worker `reelista`): Whisper large-v3-turbo на Workers AI → слова с таймкодами;
  защита — только свой Origin, 6 запросов/мин с IP, ≤ 8 МБ, только WAV, суточный потолок 500;
- слова из вырезанных пауз выпадают, растянутые Whisper'ом слова обрезаются до звучащей части;
- разбивка: по предложениям, длинные — на равные части, короткие предлоги не висят в конце строки;
- правка текста: исправленная фраза раскладывается по времени пропорционально длине слов;
- один рисовальщик для просмотра и сборки — что на экране, то и в ролике.

**v0.3 — несколько дублей и шесть стилей титров**:
- можно выбрать сразу несколько видео: склеиваются по порядку, порядок меняется стрелками, можно добавить и убрать;
- у каждого ролика свой порог тишины, начало и конец каждого дубля режутся;
- поиск дублей по тексту: фразы сравниваются по началам слов (LCS), короткая должна почти целиком входить в длинную;
  остаётся ПОСЛЕДНИЙ полный дубль, на экране «Дубли» можно выбрать другой или сказать «это не дубли»;
- вырез дубля дотягивается по звуку до следующей речи (Whisper ставит конец слова раньше, чем стихает звук),
  но только если за дублем есть настоящая тишина — иначе режем по границе Whisper;
- Whisper получает подсказку-образец речи с повторами (`initial_prompt`, по языку телефона) — без неё он
  выкидывал оборванный дубль и растягивал соседнее слово на всю пересъёмку;
- стили: Студия, Караоке, Слово, Капс, Маркер, Минимал — превью рисует тот же код, что и ролик;
- при сборке файлы сменяются в одном скрытом плеере, кадры подгоняются под размер первого ролика без чёрных полей.

**Логотип** — «волна с вырезом», вариант «Красная склейка» (19.10.2026): семейный стиль Mynado / InveStory —
тёмно-синий фон, золотой знак, плюс красная точка записи в месте вырезанной паузы.
Мастер — `icon.svg`; PNG собирает `python make-icons.py` (icon, icon-maskable, apple-touch-icon, favicon).
В шапке приложения тот же знак в цветах интерфейса (светлая волна, красная точка).
Имя бренда, кроме `BRAND` в `index.html`, записано ещё в `manifest.json` и в `<meta apple-mobile-web-app-title>`.

**v0.4 — покадровая сборка (WebCodecs).** «Живая» сборка (проигрывание + MediaRecorder) на iPhone теряла кадры:
21.7 и 15 к/с вместо 30. Теперь каждый кадр достаётся аппаратным декодером, на нём рисуются титры, и он уходит
в аппаратный кодировщик со своей меткой времени — кадры не теряются, обычно быстрее реального времени.
Библиотека — [Mediabunny](https://github.com/Vanilagy/mediabunny) 1.61.3 (MPL-2.0, файл без изменений в `vendor/`),
грузится только при первой сборке. Нет WebCodecs / не умеет кодек — автоматически старая «живая» сборка.
Проверено: 30 к/с ровно (780 из 784 промежутков = 33 мс), звук и картинка совпадают до миллисекунды на всех склейках.

**v0.6 — стили AFFX «Плашка» и «Микс»** (по `Reelista-титры-AFFX-инструкция.md`, логика перенесена из
`K:\Reels\affx-reels`: AffxCaptions.tsx и MixCaptions.tsx):
- свои фразы «как у монтажёра» (до 3 слов и 19 букв, конец после знака, служебное слово держится со следующим,
  заглавная — новое предложение) — 24 из 32 фраз совпадают с ручной нарезкой эталона Reel01;
- время: фраза за 40 мс до первого слова, первая видна с первого кадра, правило 600/300 мс по смонтированному времени;
- «Плашка»: раскладка, поля от границ заглавных («Н»), переезд 100 мс — сверено с эталонными кадрами Reel01 (±2 px);
- «Микс»: мелкие слова + крупный акцент с зачёркиванием — сверено с Reel01MG (±3 px);
- словарь замен для всех стилей, цвета плашки/акцента, свои шрифты бренда (хранятся только в браузере, IndexedDB);
- по умолчанию свободные Unbounded (вместо Benzin) и Manrope (вместо Gilroy): Benzin/Gilroy — коммерческие;
- в редакторе текста: тап по слову — акцент, долгое нажатие — зачёркивание, значок между словами — разрыв/склейка.

Выкладка воркера: `npx wrangler deploy --config worker/wrangler.toml` (с `NODE_EXTRA_CA_CERTS` из-за Avast).

## Как проверено
В Chromium на синтетическом ролике (тон = речь, белый кадр = речь):
склейки точные (проскок ≤ 9 мс), речь не обрезается, звук и картинка расходятся не больше чем на кадр (~30 мс).
**В Safari на iPhone ещё не проверено** — это и есть цель прототипа.
