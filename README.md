# Reelista

Монтаж рилсов «говорящая голова» прямо на телефоне: выбрал ролик → паузы вырезались сами → сохранил.

**Прототип v0.1** — один файл `index.html`, без сервера:
- звук ролика разбирается на устройстве (Web Audio), порог тишины подстраивается под каждый ролик;
- три уровня резки: «Мягко» / «Средне» / «Жёстко» (минимальная пауза 0.70 / 0.45 / 0.25 с, запас у слов 0.15 / 0.10 / 0.06 с);
- начало и конец ролика (тянулись к кнопке, молчали в конце) режутся всегда;
- просмотр с пропуском пауз, волна с подсвеченными вырезами, тап по волне — перемотка;
- сборка в реальном времени: canvas + MediaRecorder, между кусками запись на паузе;
- сохранение через «Поделиться» → «Сохранить видео» (на iPhone попадает в «Фото»).

Видео никуда не отправляется.

**v0.2 — титры** (два стиля: «Студия» — фраза целиком, звучащее слово красное; «Караоке» — 2–3 слова крупно, слово в плашке):
- телефон отправляет только звук: моно 16 кГц WAV (~2 МБ/мин), видео не уходит;
- сервер `worker/` (Cloudflare Worker `reelista`): Whisper large-v3-turbo на Workers AI → слова с таймкодами;
  защита — только свой Origin, 6 запросов/мин с IP, ≤ 8 МБ, только WAV, суточный потолок 500;
- слова из вырезанных пауз выпадают, растянутые Whisper'ом слова обрезаются до звучащей части;
- разбивка: по предложениям, длинные — на равные части, короткие предлоги не висят в конце строки;
- правка текста: исправленная фраза раскладывается по времени пропорционально длине слов;
- один рисовальщик для просмотра и сборки — что на экране, то и в ролике.

Выкладка воркера: `npx wrangler deploy --config worker/wrangler.toml` (с `NODE_EXTRA_CA_CERTS` из-за Avast).

## Как проверено
В Chromium на синтетическом ролике (тон = речь, белый кадр = речь):
склейки точные (проскок ≤ 9 мс), речь не обрезается, звук и картинка расходятся не больше чем на кадр (~30 мс).
**В Safari на iPhone ещё не проверено** — это и есть цель прототипа.
